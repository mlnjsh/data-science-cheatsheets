# Data Science Cheatsheets

![Contributions Welcome](https://img.shields.io/badge/contributions-welcome-brightgreen)
![License](https://img.shields.io/badge/License-MIT-green)

> Comprehensive, no-fluff cheatsheets for Data Science, Machine Learning, and AI.

Quick-reference guides covering the tools and concepts you use every day. Each cheatsheet is designed to be practical — tables, code snippets, and common patterns you can copy-paste.

---

## Cheatsheets

| # | Topic | Description |
|---|-------|-------------|
| 1 | [Python Basics](cheatsheets/python-basics.md) | Data types, comprehensions, decorators, generators, error handling |
| 2 | [NumPy](cheatsheets/numpy.md) | Arrays, indexing, broadcasting, linear algebra, random |
| 3 | [Pandas](cheatsheets/pandas.md) | DataFrames, groupby, merge, pivot tables, time series |
| 4 | [SQL](cheatsheets/sql.md) | SELECT, JOINs, GROUP BY, window functions, CTEs |
| 5 | [Statistics](cheatsheets/statistics.md) | Distributions, hypothesis testing, confidence intervals |
| 6 | [Machine Learning](cheatsheets/machine-learning.md) | Algorithm selection, metrics, cross-validation, regularization |
| 7 | [Deep Learning](cheatsheets/deep-learning.md) | Architectures, activations, loss functions, optimizers |
| 8 | [Scikit-Learn](cheatsheets/scikit-learn.md) | Preprocessing, pipelines, model selection, feature engineering |
| 9 | [Git](cheatsheets/git.md) | Commands, branching, merging, rebasing, stashing |
| 10 | [Regex](cheatsheets/regex.md) | Syntax, common patterns, Python re module |
